# Utkramit Middle School Website

A modular school website with a simple Node.js backend for handling contact form submissions.

## Features
- Responsive homepage
- About, academics, facilities, and contact sections
- Backend API for contact form submissions
- Ready for GitHub hosting deployment

## Run locally
1. Install Node.js and npm
2. Run:
   ```bash
   npm install
   npm start
   ```
3. Open http://localhost:3000

## Deploy to GitHub Pages
For static hosting, you can publish the frontend files from the repository root.
For the backend, use a service like Render, Railway, or Heroku.

## Project structure
- index.html
- styles.css
- script.js
